# 범용 민사 소장 · 지급명령 · 사실조회신청서 오프라인 통합 패키지 (버전 1 + 버전 2)

본 패키지는 **버전 1(무의존성 올인원 오프라인 파일 + 실시간 로컬 캐시 자동저장/JSON 백업)**과 **버전 2(데스크톱 독립창 실행 런처 및 Electron `.exe` 빌드 구성)**가 모두 포함된 통합 배포본입니다.

---

## 🚀 [버전 1] 올인원 오프라인 파일 + 로컬 캐시 자동저장 & JSON 파일 백업

1. **즉시 실행 방법**:
   - 폴더 내의 `민사소장_지급명령_오프라인단독실행.html` (또는 `index.html`) 파일을 더블 클릭하면 인터넷 연결이 전혀 없는 상태에서도 100% 동일한 화면으로 작동합니다.
2. **브라우저 캐시 자동저장 + 파일 백업(`.json`)**:
   - 글자를 입력하거나 단계를 이동할 때마다 로컬 저장소(`localStorage`)에 실시간으로 자동 저장되어, 창을 닫았다가 다시 열어도 작성하던 내용이 그대로 유지됩니다.
   - 상단 헤더의 **`[💾 파일백업]`** 버튼을 누르면 현재까지 입력한 모든 데이터를 `.json` 파일로 컴퓨터/스마트폰에 영구 보관할 수 있으며, **`[📂 불러오기]`** 버튼으로 언제든 복원할 수 있습니다.

---

## 💻 [버전 2] 데스크톱 독립 프로그램 실행 (`.bat` 즉시 런처 & `.exe` 빌드)

### 방법 A. 별도 설치 없이 지금 바로 독립 프로그램 창으로 실행 (Windows)
- 동봉된 **`소장작성기_독립프로그램창_실행.bat`** 파일을 더블 클릭하면, 웹 브라우저 주소창이나 탭이 없는 **전용 데스크톱 소프트웨어 창(`--app` 모드)**으로 즉시 실행됩니다.

### 방법 B. GitHub Actions 또는 로컬에서 단일 `.exe` 파일 생성하기
1. **GitHub에서 자동으로 `.exe` 만들기 (내 PC에 개발도구 설치 불필요)**:
   - 이 폴더의 파일들을 GitHub 저장소에 올린 뒤, 저장소 상단 **`Actions`** 탭 → 좌측 **`Build Offline Desktop App (.exe)`** 클릭 → 우측 **`Run workflow`** 버튼을 누르면 깃허브 서버가 자동으로 윈도우용 포터블 `.exe` 파일을 만들어 주며 하단 **Artifacts**에서 내려받을 수 있습니다.
2. **내 PC에서 직접 `.exe` 빌드하기 (Node.js 설치 시)**:
   ```bash
   npm install
   npm run dist:win
   ```
   명령을 실행하면 `dist/` 폴더 안에 설치 없이 바로 실행되는 단일 포터블 `.exe` 파일이 생성됩니다.
